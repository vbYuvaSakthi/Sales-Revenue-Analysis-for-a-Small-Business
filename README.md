# Sales & Revenue Analysis for a Small Business

## Overview
This project analyzes customer and sales transaction data to identify revenue trends, product performance, and customer spending behavior. The solution uses Python for ETL, MySQL for data storage and analysis, and Power BI for dashboard development.

## Tech Stack
- Python
- MySQL
- Power BI

## Key Features
- Data validation and cleaning using Python
- Feature engineering (Age Group, Month, Year, Quarter)
- Customer segmentation
- KPI development
- Sales and customer analysis
- Interactive Power BI dashboards

## Dashboard Modules
### Executive Dashboard
- Revenue Overview
- Revenue Trends
- Payment Method Analysis

### Product Analysis
- Top Products
- Category Performance
- Quantity Sold Analysis

### Customer Analysis
- Customer Segments
- Gender Distribution
- Age Group Analysis
- Revenue by Location

## Outcome
The project provides actionable insights into sales performance, customer behavior, and revenue trends, helping businesses make data-driven decisions and improve overall performance.
